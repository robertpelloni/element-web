# Project Vision: Element Web (robertpelloni fork)

## Ultimate Goal
To create the most complete, robust, useful, and functional Matrix web and desktop client. This project aims to push the boundaries of secure communication by implementing all planned features with extreme detail, robustness, and elegant design.

## Core Foundational Ideas
- **Magnificence & Excellence**: Every feature should be "Magnificent", "Extraordinary", and "Insanely Great".
- **Comprehensiveness**: No feature should be left partially implemented. Everything from backend to frontend UI should be 100% wired up and represented.
- **User Empowerment**: Wide breadth of options and coverage, allowing users full control over their experience.
- **Flawless UI/UX**: All UI should work perfectly, be well-documented within the interface (labels, descriptions, tooltips), and have high-quality external documentation.
- **Intelligent Integration**: Intelligently merge and solve conflicts from various feature branches to ensure no progress is lost and no regressions are caused.
- **Autonomous Evolution**: The project should continuously iterate and innovate, expanding and increasing user satisfaction and delight.

## Design Principles
- **Deep Documentation**: Detailed comments in code explaining what, why, and how.
- **Elegant Refactoring**: Constant search for more elegant designs and robust implementations.
- **Model-Specific Optimization**: Tailoring instructions for different LLM models (Claude, Gemini, GPT) to leverage their unique strengths.
- **Universal Synchronization**: Unified versioning and documentation across the monorepo.

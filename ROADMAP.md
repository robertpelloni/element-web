# Project Roadmap

## Major Structural Plans
- **Monorepo Optimization**: Continuously improve the monorepo structure for better package management and shared components across apps/web, apps/desktop, and shared packages.
- **MVVM Transition**: Proceed with the transition to MVVM v2 across the entire codebase to improve separation of concerns, snapshot management, and testability.
- **Module API Expansion**: Enhance the Module API surface (`@element-hq/element-web-module-api`) to allow more powerful third-party extensions, custom room banners, composers, and security callbacks.
- **Cross-Platform Parity**: Ensure full feature parity and design consistency between Element Web and Element Desktop, including system tray controls and deep-link lifecycle handling.
- **Advanced Audio Handling**: Stabilize and polish audio player and recorder components using the latest Web Audio standards.
- **Settings & Dashboard Consolidation**: Streamline nested settings tabs and dialogs into a consolidated, intuitive dashboard view with robust tooltips and accessible guidance.

## Upcoming Major Features
- **Enhanced Notifications**: Fully implement and polish the new notification settings and panel.
- **New Room List**: Complete the implementation and wiring of the new room list, ensuring it's robust and feature-complete.
- **Advanced Encryption UI**: Polish and improve the user interface for encryption management, device verification, and dehydrated device recovery.
- **Live Location Sharing**: Move live location sharing out of development/labs into a stable feature.
- **Group Calls (MSC3401)**: Fully integrate and stabilize the new group call experience using Element Call.
- **Sliding Sync Optimization**: Fully transition to the simplified sliding sync for improved performance in large accounts.
